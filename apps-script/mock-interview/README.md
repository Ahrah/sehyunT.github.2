# 12월 모의면접 신청: 구글 시트 + Apps Script

홈페이지 `/mock-interview/` 신청서가 이 Apps Script 웹 앱으로 신청을 보냅니다. 신청은 구글 시트 한 장에 쌓입니다.
자동 메일·문자는 보내지 않습니다. 연락은 세연쌤이 직접 합니다.

## 1. 처음 한 번 설정하기 (약 10분)

1. 세연쌤 구글 계정으로 새 구글 시트를 만듭니다. 이름 예: `12월 모의면접 신청`.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs`를 통째로 붙여 넣습니다.
4. 왼쪽 톱니바퀴(프로젝트 설정)에서 **'appsscript.json' 매니페스트 파일을 편집기에 표시**를 켭니다.
   `appsscript.json` 내용을 이 폴더의 파일로 바꿉니다(시간대 Asia/Seoul).
5. 저장한 뒤 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다.
   - 처음 실행하면 권한 요청 창이 뜹니다. 세연쌤 계정을 고르고 **허용**을 누릅니다(한 번만).
   - '확인되지 않은 앱' 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 세연쌤이 직접 만든 스크립트라 나오는 안내입니다.
   - 실행이 끝나면 시트에 `신청` 탭과 머리글이 생기고, 5분마다 도는 정리 트리거가 생깁니다.
6. **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. 웹 앱 URL을 홈페이지 빌드 값 `VITE_MOCK_INTERVIEW_API_URL`에 넣습니다.
   - 이 주소는 비밀번호가 아닙니다. 그래도 채팅·문서에 붙이지 말고 저장소 설정(Variables)에만 넣습니다.
   - 주소가 비어 있으면 미리보기에서는 '미리보기(테스트 모드)'로, 실제 홈페이지에서는 '신청 접수 준비 중'으로 보입니다.
8. 시트를 새로고침하면 위 메뉴에 **모의면접**이 생깁니다.
   - **지금 정리하기**: 5분을 기다리지 않고 바로 확정·취소·대기 승격을 합니다.

코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. URL은 그대로입니다.

## 2. 매일 할 일

| 할 일 | 시트에서 하는 것 |
| --- | --- |
| 입금 확인 | `입금 확인` 체크 + `입금 시각`에 은행 앱의 입금 시각 입력(예: `2026-11-09 21:40`) |
| 입금이 안 들어옴 | `입금 기한`이 지난 뒤 `미입금` 체크 |
| 서류 받음 | `서류 받음` 체크 |
| 대기자가 입금 대기로 바뀜 | `처리 기록`에 '승격'이 찍힙니다. 휴대폰으로 직접 연락합니다 |

5분마다 스크립트가 다음을 합니다.

- `입금 확인` + `입금 시각`이 `입금 기한` 안 → **확정**
- `입금 시각`이 `입금 기한` 뒤 → **취소**(사유: 기한 뒤 입금, 환불 안내 필요)
- `입금 기한`이 지났고 `미입금` 체크 → **취소**
- 확정인데 `서류 기한`(면접 7일 전 밤 12시)까지 `서류 받음`이 비어 있음 → **취소**(사유: 서류 미제출)
- 자리가 나면 대기 1번을 **입금 대기**로 바꾸고 그때부터 새 1시간 기한을 줍니다.
  면접 24시간 전부터는 승격하지 않습니다.

`미입금`을 체크하지 않으면 기한이 지나도 자동으로 취소하지 않습니다. 밤늦게 들어온 입금을 놓치지 않으려는 장치입니다.
`입금 대기` 자리도 정원에 들어갑니다.

## 3. 시트 칸 설명 (`신청` 탭)

스크립트가 쓰는 칸: `상태`, `대기 순번`, `입금 기한`, `서류 기한`, `입금 대기 시작`, `취소 사유`, `처리 기록`. 이 칸은 손으로 고치지 않습니다.
세연쌤이 쓰는 칸: `입금 확인`, `입금 시각`, `미입금`, `서류 받음`, `메모`.

| 칸 | 내용 |
| --- | --- |
| 신청번호 | MI-월일-시분초-숫자 |
| 신청 시각 | 신청서를 보낸 시각(한국 시간) |
| 구분 | 예약(10·11·12시) / 요청(13~17시·평일) |
| 날짜, 시간 | 예약한 타임. 요청은 비어 있음 |
| 상태 | 입금 대기 / 확정 / 대기 / 취소 / 요청 접수 |
| 대기 순번 | 대기일 때 1, 2, 3… |
| 입금 기한 | 입금 대기 시작 + 1시간 |
| 입금 확인, 입금 시각, 미입금 | 세연쌤이 입력 |
| 서류 기한 | 면접 7일 전 23:59. 그 뒤에 자리를 받은 학생은 자리 받은 때 + 24시간 |
| 서류 받음 | 세연쌤이 체크 |
| 학생 이름 ~ 입금자명 | 신청서 내용(휴대폰은 숫자만) |
| 희망 일시(요청) | 요청일 때 적은 날짜·시간 |
| 만 14세 미만, 보호자 이름, 보호자 연락처, 보호자 동의(+시각) | 만 14세 미만일 때만 |
| 개인정보 / 영상 / 사진 동의(+시각) | Y/N과 동의한 시각 |
| 입금 대기 시작 | 자리를 잡은 시각(승격이면 승격 시각) |
| 취소 사유, 처리 기록 | 스크립트가 남기는 기록 |
| 메모 | 자유롭게 |

## 4. 바꾸고 싶을 때

`Code.gs` 맨 위 `MI`와 홈페이지 `src/lib/mockInterview.ts`의 `MI_CONFIG`를 **둘 다** 같이 고칩니다.
`npm test`가 두 값이 같은지 확인합니다.

- 사진 동의를 선택으로 바꾸기: `PHOTO_CONSENT_REQUIRED` / `photoConsentRequired`를 `false`로
- 정원, 날짜, 시간, 오픈 시각도 같은 곳에 있습니다.

## 5. 개인정보

- 보관: 면접 후 6개월이 지나면 해당 줄을 지웁니다(자동 삭제는 아직 없음).
- 영상: 보낸 날로부터 7일 안에 지웁니다.
- 사진: 얼굴 모자이크, 2년 보관. 철회 요청이 오면 올린 사진을 내리고 `사진 동의`를 N으로 고친 뒤 `메모`에 날짜를 남깁니다.
- 시트 공유는 세연쌤 계정만 둡니다.
