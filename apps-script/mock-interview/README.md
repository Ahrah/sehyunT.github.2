# 12월 모의면접 신청: 구글 시트 + Apps Script

홈페이지 `/mock-interview/` 신청서가 이 Apps Script 웹 앱으로 신청을 보냅니다. 신청은 세연쌤 구글 시트에 쌓입니다.

- `신청` 탭: 16·17·18시 예약과 대기. 한 번에 여러 타임을 신청하면 **타임마다 한 줄**이 생기고, 같은 `묶음 번호`를 씁니다(아래 2번 '여러 타임 신청').
- `추가 오픈 신청` 탭: 신청서에서 '추가 오픈 신청'을 누른 사람이 신청완료 화면에서 고른 희망 날짜·희망 시간(여러 개)과 이름·연락처. 입금은 없고 자리를 잡지 않습니다. 이용 목적은 '대기·추가 타임 연락'이며, 12/20까지 보관 후 삭제합니다(12/20 밤 12시가 지나면 스크립트가 지웁니다).
- 입금 확인은 **손으로** 합니다(기본). 세연쌤이 `입금 확정`에 체크하면 바로 `확정`으로 바뀌고, 세연쌤 메일로 확정 안내 메일이 옵니다. 학생 예약확정 문자는 `[문자발송] 모의면접` 메일로 따로 오고, 세연쌤 iPhone 단축어가 문자로 보냅니다(아래 '학생 문자').
  학생 이메일은 받지 않으므로 학생에게 직접 메일을 보내지 않습니다. 학생 연락은 문자·카카오로 합니다.

## 1. 처음 한 번 설정하기 (약 10분)

1. 세연쌤 구글 계정(consultantsyssam@gmail.com)으로 새 구글 시트를 만듭니다. 이름 예: `12월 모의면접 신청`.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs`를 통째로 붙여 넣습니다.
4. 왼쪽 톱니바퀴(프로젝트 설정)에서 **'appsscript.json' 매니페스트 파일을 편집기에 표시**를 켭니다.
   편집기에 생긴 `appsscript.json` 내용을 이 폴더의 파일로 바꿉니다(시간대 Asia/Seoul, 권한 목록).
5. 저장(디스크 아이콘)한 뒤 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다.
   - 권한 요청 창이 뜹니다. **권한 검토 → 세연쌤 계정 선택**.
   - '확인되지 않은 앱' 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)**을 누릅니다. 세연쌤이 직접 만든 스크립트라 나오는 안내입니다.
   - 허용할 권한은 4가지입니다. 모두 **허용**을 누릅니다.
     - 이 스프레드시트 보기·수정(시트)
     - 내 이름으로 이메일 보내기(확정·확인 필요 알림 메일과 `[문자발송]` 메일, 받는 사람은 세연쌤 본인)
     - 트리거 만들기(5분마다 정리, 체크하면 바로 정리)
     - 시트 안에 메뉴 표시
   - Gmail 읽기와 구글 드라이브 권한은 요청하지 않습니다. 입금 알림 자동 확인(아래 5번)을 켤 때만 Gmail 권한이 추가됩니다.
   - 실행이 끝나면 `신청`, `추가 오픈 신청` 탭과 머리글, 트리거 2개(5분마다, 수정할 때)가 생깁니다.
6. **배포 → 새 배포 → 톱니바퀴 → 웹 앱**을 고릅니다.
   - 설명: `모의면접 신청`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. 웹 앱 URL을 홈페이지 빌드 값 `VITE_MOCK_INTERVIEW_API_URL`에 넣습니다(GitHub 저장소 Settings → Secrets and variables → Actions → Variables).
   - 채팅·문서에 붙이지 말고 저장소 설정에만 넣습니다.
   - 주소가 비어 있으면 미리보기에서는 '미리보기(테스트 모드)'로, 실제 홈페이지에서는 '신청 접수 준비 중'으로 보입니다.
8. 시트를 새로고침하면 위 메뉴에 **모의면접**이 생깁니다.
   - **지금 정리하기**: 바로 확정·취소·대기 승격을 합니다.
   - **선택한 줄 관리자 취소(대기 1번 승격)**: `신청` 탭에서 줄을 고르고 누르면 그 신청을 `관리자 취소`로 바꾸고 대기 1번을 입금 대기로 올립니다.
8-1. 관리자 화면 키: **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 속성 추가**에서 이름 `MI_ADMIN_KEY`, 값은 20자 이상 아무 글자(비밀번호 관리 앱에서 만든 값)를 넣습니다.
   - 홈페이지 `sehyunt.re.kr/mock-interview/?admin`을 열고 이 키를 넣으면 관리자 화면이 열립니다. 키는 그 탭에만 남습니다.
   - 키를 10번 틀리면 10분 동안 받지 않습니다. 키를 비워 두면 관리자 화면은 열리지 않습니다.
8-2. 마감 임박 알림(세연님 11/3 결정): 같은 스크립트 속성 화면에서 두 가지를 넣습니다.
   - `OWNER_PHONE`: 세연님 휴대폰 번호(숫자만, 예 `010` 으로 시작하는 11자리). 이 번호로 `[문자발송] 모의면접` 메일이 가고 iPhone 단축어가 문자로 보냅니다. 문자: `[마감임박] 12월 19일 17시 3:1 모의면접 남은 자리 1명`.
   - `ALERT_EMAIL`: 카카오채널 봇이 읽는 메일 주소. 제목 `[마감임박] 3:1 모의면접`, 본문 첫 줄 `날짜: 12월 19일(토)`, `시간: 17시`, `남은 인원: 1`. 봇은 이 메일을 보고 '마감 임박! 이후 대기 신청만 가능합니다'를 올립니다. 비워 두면 보내지 않습니다.
   - 언제: 다른 타임이 모두 차서(대기만 받거나 신청 마감) 새로 신청할 수 있는 타임이 하나만 남고, 그 타임 남은 자리가 1명이 되었을 때. 타임마다 보내지 않습니다.
   - 한 번만 보냅니다. 보낸 기록은 스크립트 속성 `MI_LAST_SEAT` 에 스크립트가 남깁니다(고치지 마세요). 자리가 다시 비거나 추가 타임을 열어 조건이 풀렸다가 다시 1명이 되면 또 보냅니다.
   - 오픈(`MI.SMS_SINCE`, 11/9 21:00) 전에는 보내지 않습니다. 관리자 화면 신청 목록에서는 그 타임에 빨간 `마감 임박` 표시가 붙습니다.
9. 시험: 브라우저 시크릿 창에서 웹 앱 URL을 열면 `{"ok":true,...}`가 보여야 합니다.

코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. URL은 그대로입니다.

## 2. 입금 확정(손으로 체크하는 방식)

1. 은행 앱에서 입금을 봅니다. 금액(80,000원 × 그 묶음의 입금 대기 타임 수), 입금자명이 시트 `입금자명`과 같은지 봅니다.
2. 그 줄의 **`입금 확정`** 칸에 체크합니다.
3. (선택) `입금 시각`에 은행에 찍힌 시각을 적습니다. 예: `2026-11-09 21:40`.
   - 이 시각이 `입금 기한` + 10분 안이면 제때 입금으로 보고 확정합니다.
   - `입금 기한` + 10분 뒤면 확정하지 않고 **확인 필요**로 바꾸고 세연쌤 메일로 알립니다.
   - 비워 두면 체크한 시각으로 판단합니다. `입금 기한` + 10분 안에 체크하면 확정합니다.
4. 체크하면 몇 초 안에 `상태`가 **확정**으로 바뀌고, 세연쌤 메일로 `[모의면접] 예약 확정` 메일과 `[문자발송] 모의면접` 메일(학생 예약확정 문자)이 옵니다. 문자는 iPhone 단축어가 보냅니다.

| 할 일 | 시트에서 하는 것 |
| --- | --- |
| 입금 들어옴 | `입금 확정` 체크(필요하면 `입금 시각`) |
| 입금이 안 들어옴 | 할 일 없음. `입금 기한` + 10분이 지나면 자동 취소, 대기 1번 승격, 미입금 취소 `[문자발송]` 메일(신청 하나에 한 통). 더 빨리 정리하려면 기한 뒤 `미입금` 체크(바로 취소) |
| 학생이 카카오채널로 취소를 요청함 | 관리자 화면 `신청 목록`에서 그 줄의 **취소**(또는 시트 메뉴 **선택한 줄 관리자 취소**). 대기 1번이 입금 대기(8시간 + 10분)로 올라가고 승격 `[문자발송]` 메일이 옵니다. 두 번 눌러도 한 번만 처리합니다. 환불은 환불 기준대로 직접 보냅니다. **`상태` 칸을 손으로 `취소`로 바꾸면 대기가 올라가지 않습니다** |
| `확인 필요` 메일이 옴 | 그 타임에 빈자리가 있으면 `상태`를 **확정**으로 직접 바꿉니다. 없으면 환불하고 `메모`에 적습니다 |
| 서류 받음 | `서류 받음` 체크 |
| 대기자가 입금 대기로 바뀜 | `[문자발송] 모의면접` 메일이 옵니다. iPhone 단축어가 승격 문자를 보냅니다 |
| 추가 날짜·시간을 열기로 함 | 관리자 화면 `타임 추가 열기`에서 날짜·시간을 넣고 **타임 열고 알림 보내기**. 신청 페이지에 바로 나타나고(스크립트 속성 `MI_EXTRA_SLOTS`), 그 날짜를 원한 추가 오픈 신청자에게 알림 `[문자발송]` 메일이 한 사람에 한 통 옵니다(같은 날짜는 다시 보내지 않고, `오픈 알림 기록` 칸에 남깁니다). '추가 오픈 신청자 모두'를 고를 수도 있습니다. 관리자 화면 `추가 오픈 신청` 탭에서 신청자 목록(이름·연락처·희망 날짜·시간·신청 시각)을 봅니다 |

스크립트가 하는 일(5분마다, 그리고 체크할 때마다):

- `입금 확정` 체크 → **확정**(+ 세연쌤에게 알림 메일)
- `입금 시각`(없으면 체크한 시각)이 `입금 기한` + 10분 뒤 → **확인 필요**(+ 세연쌤에게 메일). 자동으로 확정하지 않습니다
- `입금 확정` 없이 `입금 기한` + 10분이 지남 → **취소**(취소 사유 `미입금(입금 기한 … + 10분 지남)`)
- `입금 기한`이 지났고 `미입금` 체크 → 10분을 기다리지 않고 **취소**(취소 사유 `미입금(미입금 체크)`)
- 미입금으로 취소된 줄에 `입금 확정`(또는 `입금 시각`)이 들어옴 → **확인 필요**(+ 메일). 자동으로 예약하지 않습니다
- `서류 기한`(면접 7일 전 밤 12시)까지 `서류 받음`이 비어 있어도 **취소하지 않습니다**. 서류를 내지 않아도 면접은 그대로 진행하며, 당일 즉석 질문으로 진행합니다(세연님 11/3 결정, `MI.CANCEL_WITHOUT_DOCS = false`).
- **대기 승격 규칙**: 12/12 16:00·12/20 18:00(처음부터 대기로 받는 타임)은 대기 신청이 2명이 되면 대기 순서대로 입금 대기로 올립니다. 나머지 타임은 **앞선 신청자가 취소될 때만**(미입금 자동 취소, 관리자 취소) 그 자리 수만큼 올립니다. `확인 필요`·서류 미제출로는 올리지 않습니다. 학생이 직접 취소하는 기능은 없고, 화면에는 '신청 취소를 원하시면 카카오채널 입시는세연쌤으로 문의해 주세요.'가 나옵니다.
- 자리가 나면 대기 1번부터 **입금 대기**로 바꾸고 승격 시각부터 **8시간** 기한을 줍니다(`MI.PROMOTED_PAY_WINDOW_MS`). 기한 + 10분이 지나면 똑같이 자동 취소됩니다. 면접 24시간 전부터는 승격하지 않습니다.
- 승격되면 승격된 학생마다 `[문자발송] 모의면접` 메일이 한 통씩 옵니다(아래 '학생 문자'). 예: `[입시는세연쌤] 대기 1번 홍길동 학생, 현재 12월 12일 16시 3:1 모의면접 신청 가능합니다. 8시간 이내(12월 3일 22:00까지)에 입금 완료해 주시면 예약이 확정됩니다. 입금 계좌: …, 80,000원`
- `확정`이 된 예약은 묶음마다 `[문자발송] 모의면접` 메일(예약확정 문자)이 한 통 옵니다.

### 학생 문자(`[문자발송]` 메일 → iPhone 단축어)

문자 API는 쓰지 않습니다. 스크립트가 세연쌤 메일로 아래 형식의 메일을 보내고, 세연쌤 iPhone의 단축어 자동화(이메일 트리거, 제목에 `[문자발송]` 포함)가 메일을 읽어 '메시지 보내기'로 보냅니다. 세연쌤 번호와 요금제로 나갑니다.

```
제목: [문자발송] 모의면접
받는번호: 01012345678
문자: [입시는세연쌤] 홍길동 학생, 12월 12일 17시 3:1 모의면접 예약이 확정되었습니다. 서류는 언제 보내나요? …

신청번호: MI-…-1 (묶음 MI-…)
시트 행: 5
…
```

- 제목은 늘 `[문자발송] 모의면접`(`MI.SMS_SUBJECT`)입니다. 다른 알림 메일 제목에는 `[문자발송]`이 들어가지 않습니다.
- 첫 줄은 `받는번호: 숫자만`, 둘째 줄은 `문자: 한 줄 문자`입니다. 빈 줄 뒤는 사람이 보는 내용입니다(이 부분에는 `받는번호:`·`문자:`를 쓰지 않습니다). 단축어 정규식: `받는번호:\s*(\d+)`, `문자:\s*(.+)`.
- 대기 승격: 이번 정리에서 올라간 줄마다 한 통. 입금 기한이 함께 적힙니다.
- 예약확정: `상태`가 `확정`인 예약 줄을 묶음마다 모아 한 통. `입금 확정`을 세금 봇이 체크했든 세연쌤이 체크했든, `확인 필요`를 세연쌤이 손으로 `확정`으로 바꿨든 같습니다.
- 다시 보내지 않기: 보낸 줄의 `처리 기록`에 `… 예약확정 문자 메일 보냄`(승격은 `… 승격 문자 메일 보냄`)을 남깁니다. 이 표시가 있으면 다시 보내지 않습니다. 새 열은 만들지 않았습니다.
- 메일이 실패하면(하루 메일 한도 등) 예약확정은 표시를 지워 5분 뒤 다시 보냅니다. 승격은 `처리 기록`에 `승격 문자 메일 실패(직접 보내 주세요)`를 남깁니다.
- 미입금 취소: 미입금으로 자동 취소된 신청(묶음·입금 단위)마다 한 통. 문자: `[입시는세연쌤] 3:1 모의면접 신청이 미입금으로 취소되었습니다.` 표시는 `… 미입금 취소 문자 메일 보냄`, 실패하면 `미입금 취소 문자 메일 실패(직접 보내 주세요)`.
- 추가 타임 알림: 관리자 화면에서 타임을 열 때 추가 오픈 신청자에게 한 통. 문자: `[입시는세연쌤] 3:1 모의면접 추가 날짜(12월 26일 16시)가 열렸습니다. 신청 페이지에서 먼저 신청하신 순서대로 접수됩니다. sehyunt.re.kr/mock-interview`. 표시는 `추가 오픈 신청` 탭 `오픈 알림 기록` 칸(맨 끝 열)에 남깁니다.
- 관리자 취소된 학생 본인에게는 문자를 보내지 않습니다(카카오채널에서 이미 이야기한 경우라서).
- 휴대폰 번호가 010 형식이 아니면 보내지 않고 `처리 기록`에 `… 못 보냄(휴대폰 번호 확인 필요)`을 남깁니다.
- 오픈 전(`MI.SMS_SINCE`, 11/9 21:00 전)에 신청한 시험 줄에는 예약확정 문자를 보내지 않습니다. 시트로 미리 시험하려면 이 값을 잠깐 앞당기고, 시험 줄 휴대폰에는 세연쌤 번호를 넣습니다.
- 끄려면 `MI.SMS_BY_MAIL = false`. 그러면 예전처럼 `[모의면접] 대기 승격` 메일과 확정 메일 안의 문자 문구로 직접 보냅니다.
- 일정 변경(1회)으로 타임을 바꾼 줄은 표시가 남아 있어 다시 보내지 않습니다. 바뀐 일정은 직접 알려 줍니다.
- 12/20이 지나면 `추가 오픈 신청` 탭(예전 이름 `오픈 알림 신청` 탭이 남아 있으면 그 탭도)의 연락처 줄을 지웁니다.

### 여러 타임 신청(묶음)

- 학생은 타임을 여러 개 골라 신청서를 한 번 보냅니다. 시트에는 타임마다 한 줄이 생깁니다. `신청번호`는 `묶음 번호-1`, `묶음 번호-2`처럼 붙습니다.
- 한 줄에 여러 타임을 넣지 않은 까닭: 정원·대기 순번·서류 기한·취소가 모두 타임 단위이고, 세무 관리 봇도 한 줄씩(`입금 시각`·`입금 확정`·`메모`, 상태 `입금 대기`) 처리합니다. 한 줄 = 한 타임을 지키면 이 약속이 그대로 유지됩니다.
- 자리가 있는 타임은 모두 `입금 대기`이고 입금 기한이 같습니다. 이 줄들을 **입금 묶음**이라 부릅니다. 학생은 합계(80,000원 × 타임 수)를 **한 번에** 입금합니다.
- 입금 묶음 안 **한 줄만** `입금 확정`(또는 `입금 시각`)을 적어도 묶음 전체가 함께 확정됩니다. 다른 줄의 체크 칸은 스크립트가 채우지 않고 `상태`와 `처리 기록`만 바꿉니다. 모든 줄에 체크해도 됩니다.
- 기한 + 10분이 지나면 묶음 전체가 함께 취소되고, 기한 뒤 입금이면 묶음 전체가 `확인 필요`가 됩니다.
- 자리가 다 찬 타임은 `대기`로 들어갑니다. 대기 줄은 나중에 승격될 때 새 8시간 기한을 받고, 그때 따로 입금합니다(새 입금 묶음).
- 알림 메일은 입금 묶음마다 한 통이고, 타임 목록과 합계 금액이 들어 있습니다. 손으로 체크할 때는 금액이 합계와 같은지 꼭 봅니다(일부만 입금된 경우를 스크립트가 알 수 없습니다).

### 입금 기한과 10분 여유

- 입금 기한은 신청 뒤 1시간입니다. 대기에서 승격된 학생은 승격 시각부터 새 8시간입니다(면접 24시간 전부터는 승격하지 않으므로 8시간 + 10분은 늘 면접 전에 끝납니다).
- 자동 취소는 `입금 기한` + 10분(`PAY_GRACE_MS`)이 지난 뒤에 합니다. 은행 알림이나 체크가 조금 늦어도 제때 낸 입금을 취소하지 않으려는 여유입니다.
- 상태 값: `입금 대기` / `확정` / `대기` / `취소` / `확인 필요`. 미입금 자동 취소도 `취소`이고, `취소 사유`가 `미입금(`으로 시작합니다.
- `확인 필요` 줄은 자리를 잡지 않습니다. 그래서 그 자리는 대기 1번에게 넘어갈 수 있습니다. 세연쌤이 확정하려면 정원을 먼저 봅니다.
- 오픈 때부터 대기 타임: 12/12(토) 16시, 12/20(일) 18시는 처음부터 `대기`로만 받습니다. 그 타임 대기가 2명이 되면 신청 순서대로 `입금 대기`로 올리고(각자 새 8시간 기한), 학생마다 `[문자발송] 모의면접` 메일이 옵니다. iPhone 단축어가 문자를 보냅니다. 바꾸려면 `MI.WAITLIST_AT_OPEN`, `MI.WAITLIST_RELEASE_COUNT` 를 고칩니다.
- 홈페이지에는 남은 자리·대기 인원 숫자를 보내지 않습니다. 대기로 바뀐 타임만 '(대기)'로 보입니다.
- 두 번 누름: 같은 휴대폰·같은 타임이 `입금 대기`·`확정`이면 새 줄을 만들지 않고 기존 신청을 보여 줍니다(이름까지 같을 때만. 이름이 다르면 채널로 문의하라는 안내만 나옵니다).
- 내 신청 확인 링크: 신청완료 화면에 `?check=신청번호&k=확인 키` 링크와 복사 버튼이 나옵니다. 열면 상태·타임·금액·계좌·입금 기한·환불 안내를 다시 봅니다. 키가 맞지 않으면 아무것도 보여 주지 않습니다. 휴대폰 번호는 돌려주지 않습니다.
- 이번 코드를 넣은 뒤 **setup 을 한 번 다시 실행**하면 `확인 키` 열이 `신청` 탭 맨 뒤에 붙습니다(앞서 붙인 `확인 필요 사유`·`묶음 번호` 열이 없으면 함께 붙습니다). 그 전에 들어온 줄은 확인 키가 비어 있어 확인 링크가 열리지 않습니다.
- 앞서: `확인 필요 사유`·`묶음 번호` 열이 `신청` 탭 맨 뒤에, `모의면접 신청번호` 열이 `추가 오픈 신청` 탭 맨 뒤에 붙습니다. 있던 열은 옮기지 않습니다.

세연쌤이 쓰는 칸: `입금 확정`, `입금 시각`, `미입금`, `서류 받음`, `메모`.

- 홈페이지 흐름: 신청서 위 날짜마다 있는 '추가 오픈 신청' 버튼(또는 '목록에 없는 날짜')을 누르고 신청서를 보내면, 신청완료 화면에서 원하는 날짜·시간을 고르고 보냅니다. 따로 된 신청 칸은 없습니다. 개인정보 동의는 신청서 동의 하나로 합쳤습니다.

- 희망 시간: 10:00~20:00 중 고른 시간(`EXTRA_REQUEST_TIMES`, 여러 개)과 직접 적은 글(최대 40자).

- 예전 버전으로 setup을 이미 돌려 `오픈 알림 신청` 탭이 있다면, setup을 다시 돌려 `추가 오픈 신청` 탭을 만들고 예전 탭은 지워도 됩니다.

## 4. 바꾸고 싶을 때

`Code.gs` 맨 위 `MI`와 홈페이지 `src/lib/mockInterview.ts`의 `MI_CONFIG`를 **둘 다** 고칩니다. `npm test`가 두 값이 같은지 확인합니다.

- 사진 동의를 선택으로: `PHOTO_CONSENT_REQUIRED` / `photoConsentRequired`를 `false`로
- 알림 메일 끄기: `NOTIFY_OWNER: false`
- 정원, 날짜, 시간, 오픈 시각도 같은 곳에 있습니다.

## 5. (선택, 기본 꺼짐) [입금알림] 메일 자동 확인

카카오뱅크 앱 푸시를 안드로이드 'SMS 자동전달' 앱이 `[입금알림]` 제목 메일로 보내 주는 환경이 생기면 켤 수 있습니다. 지금은 꺼져 있습니다.

1. 실제 알림 메일 1통으로 문구를 확인합니다(금액·입금자명이 들어 있는지). `mi_parseDepositMail`이 그 문구를 읽는지 시험합니다.
2. `Code.gs`에서 `AUTO_DEPOSIT_CHECK: true`로 바꿉니다.
3. `appsscript.json`의 `oauthScopes`에 `"https://mail.google.com/"`를 넣습니다.
4. `setup`을 다시 실행해 Gmail 권한을 허용하고, 새 버전으로 배포합니다.

켜면 5분마다 최근 2일의 `[입금알림]` 메일을 읽고, 입금자명과 금액(80,000원 × 묶음 타임 수)이 **입금 묶음 1개와만** 맞을 때 그 묶음 모든 줄의 `입금 확정`과 `입금 시각`(메일 받은 시각)을 채웁니다.
맞는 신청이 없거나 2건 이상이면 `입금알림 기록` 탭에 '손으로 확인'으로 남깁니다.
